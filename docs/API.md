<a id="常量-格式版本"></a>

## 常量 `格式版本`

`.yj` 格式的主版本。

```yanxu
公 定 格式版本：数；
```

类型：[`数`](#类型-数)

<a id="常量-库版本"></a>

## 常量 `库版本`

言据库的语义版本。

```yanxu
公 定 库版本：文；
```

类型：[`文`](#类型-文)

<a id="法-解析"></a>

## 法 `解析`

解析一个完整言据文档；格式错误会抛出带字符位置的误。

```yanxu
公 法 解析（原文：文）：数|文|理|空|列|典；
```

归值：[`数`](#类型-数) | [`文`](#类型-文) | [`理`](#类型-理) | [`空`](#类型-空) | [`列`](#类型-列) | [`典`](#类型-典)

参数：

- `原文`：[`文`](#类型-文)
